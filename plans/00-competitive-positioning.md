# Competitive Positioning

## Message

> One complete procurement lifecycle — all capabilities buyers get from TendSign and e-Avrop, redesigned AI-native and admin-controlled.

## What we are

| We are | We are not |
|--------|------------|
| One lifecycle covering TendSign + e-Avrop **capabilities** | A clone of both UIs |
| Single module per capability | Duplicate Q&A / award / bid flows |
| AI extras on the same steps | A separate “AI product” |
| Admin entitlements per account | Uncontrolled feature sprawl |
| Existing PrequaliQ visual system | Competitor-skinned screens |

## Capability sources

### TendSign-class
Planera, Underlag, Annonsera, leverantörskonto, sök/bevaka, Q&A, anbud, sealed bids, komplettering, prövning, utvärdering, tilldelning, avtalsspärr, avtal/efterannonsera.

### e-Avrop-class
Full digital loop, ramavtal + avrop, avtalsdatabas, direktupphandling, DIS, API/integrations, contract findability for verksamhetsbeställare.

### PrequaliQ extras
AI profile / underlag / anbud assist, completeness check, prövning risk flags, evaluation copilot, Q&A drafts, annons draft, award memo, CPV recommender, supplier matching, dynamic admin feature control.

## Differentiator stack

1. **Coverage** — end-to-end Swedish public procurement jobs-to-be-done  
2. **AI-native** — assist at each step with review-before-apply  
3. **Admin control** — approve accounts; unlock modules per org  
4. **Unified UX** — one theme (see UI objects plan)
